LANGUAGE SWITCHER

Add a professional Language Switch option in the website header and inside the AI Virtual School Guide.

Languages Supported:

🇮🇳 Hindi

Display a language toggle button in the top-right corner of the navigation bar.

Example:

🌐 Language

▼

English

Hindi

OR

🌐 EN | हिंदी

================================================
LANGUAGE SWITCH FUNCTIONALITY
================================================

When the visitor selects English:

• Entire website content should change to English.
• Navigation Menu should switch to English.
• AI Virtual Guide should speak in a natural English Male Voice.
• All buttons, forms, alerts, tooltips, and messages should appear in English.

When the visitor selects Hindi:

• Entire website content should switch to Hindi.
• Navigation Menu should switch to Hindi.
• AI Virtual Guide should automatically switch to a natural Hindi Male Voice.
• All buttons, forms, alerts, tooltips, and messages should appear in Hindi.

The language preference should be saved in Local Storage, so when the visitor returns to the website, the previously selected language remains active automatically.

================================================
AI GUIDE LANGUAGE DETECTION
================================================

The AI Virtual School Guide should automatically detect the currently selected website language.

If English is selected:
• Speak in Natural English Male Voice.

If Hindi is selected:
• Speak in Natural Hindi Male Voice.

The guided website tour should also automatically switch to the selected language.
